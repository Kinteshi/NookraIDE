The first release of QuireCode: a native code editor for Android tablets, with a Linux machine behind it. The
editor, Explorer, terminals, notebooks and Git run in the app; the language servers, debuggers, Jupyter kernels and
tools run in the Linux guest of Android's Linux Terminal, through a small daemon the app installs there.

## What you need

* An Android tablet with Android 14 or later and the **Linux Terminal** app (Android's virtualization framework, turned
  on in Developer options), set up with its Debian guest. Made and tested on a Galaxy Tab S11 Ultra.
* A hardware keyboard is recommended; the on-screen keyboard works too.

## Installing

1. Install `quirecode-0.1.0.apk` from this release.
2. Open Linux Terminal once, so the guest is running.
3. In QuireCode, choose **Set up the guest** and follow it: it copies the daemon and its installer to Downloads and
   gives you one command to paste in Linux Terminal. That installs the daemon and its tools and prints a pairing code;
   enter it in the app. The [README](https://github.com/Kinteshi/QuireCode#readme) has the details.

The daemon is also attached for Linux and WSL machines (`quirecode-daemon-0.1.0-linux-x86_64`, `-linux-arm64`), to use the app
with a computer instead. `SHA256SUMS` lists every file's checksum.

## In this release

* **Editor:** VS Code's keybindings and settings, TextMate grammars and themes, multi-language intelligence through
  language servers in the guest (suggestions, hover, parameter hints, inlay hints, code lenses, go to definition,
  rename, code actions, formatting, problems), folding, snippets, find and replace, linked tag editing, Markdown and SVG
  previews, a read-only view for large files.
* **Notebooks:** Jupyter notebooks with kernels in the guest, rich outputs (tables, plots, and many widgets), and cells
  edited with the code editor: its colours, folding and several cursors, line numbers if you want them, and its
  intelligence (completions, problems, hover, Copilot).
* **Terminals, Git, debugging:** terminals in the guest, Source Control, and debugging through `launch.json`
  (breakpoints, conditional breakpoints and logpoints, variables, watch, inline values).
* **Copilot and Chat:** GitHub Copilot's inline suggestions and next edits, and a chat with Copilot or another agent.
* **Offline:** with the guest away, the last folder's files open from this device's copies, and saves wait for the guest.
* **Material You** throughout: dynamic colour, light and dark, and a pure black option.

## Known limits

* Android may stop the guest when the tablet is low on memory, or when apps start many background processes; the app
  says so and how to start it again.

To report a problem, use **Settings > About > Copy diagnostics** and paste the report into an issue. QuireCode has no
telemetry.
