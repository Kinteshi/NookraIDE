The first release of Nookra IDE: a native code editor for Android tablets, with a Linux machine behind it. The
editor, Explorer, terminals, notebooks and Git run in the app; the language servers, debuggers, Jupyter kernels and
tools run in the Linux guest of Android's Linux Terminal, through a small daemon the app installs there.

## What you need

* An Android tablet with Android 14 or later and the **Linux Terminal** app (Android's virtualization framework, turned
  on in Developer options), set up with its Debian guest. Made and tested on a Galaxy Tab S11 Ultra.
* A hardware keyboard is recommended; the on-screen keyboard works too.

## Installing

1. Install `quirecode-0.1.0.apk` from this release.
2. Open Linux Terminal once, so the guest is running.
3. In Nookra IDE, choose **Set up the guest** and follow it: it copies the daemon and its installer to Downloads and
   gives you one command to paste in Linux Terminal. That installs the daemon and its tools and prints a pairing code;
   enter it in the app. The [README](https://github.com/Kinteshi/QuireCode#readme) has the details.

The daemon is also attached for Linux and WSL machines (`quirecode-daemon-0.1.0-linux-x86_64`, `-linux-arm64`), to use the app
with a computer instead. `SHA256SUMS` lists every file's checksum.

## In this release

* **Editor:** VS Code's keybindings and settings, built-in syntax highlighting for 20 languages out of the box plus
  TextMate grammar packs and imported VS Code themes, multi-language intelligence through language servers in the guest
  (suggestions, hover, parameter hints, inlay hints, code lenses, go to definition, rename, code actions, formatting,
  problems), folding, snippets, find and replace, linked tag editing, Markdown and SVG previews, hex and image viewers,
  and a read-only view for large files.
* **Notebooks:** Jupyter notebooks with kernels in the guest, rich outputs (native tables, plots, interactive widgets
  including media, pickers, `Play`, `jslink`, `@jupyter-widgets/html-manager` / `anywidget`, and saved widget state),
  and code cells edited with the full code editor (colours, folding, multiple cursors, line numbers, completions,
  problems, hover, and Copilot).
* **Terminals, Git, debugging:** terminals in the guest, Source Control with diff and hunk staging, and debugging
  through `launch.json` (breakpoints, conditional breakpoints and logpoints, hover values while paused, variables,
  watch, and inline values).
* **Copilot and Chat:** GitHub Copilot's inline suggestions (with word-by-word accept via `Ctrl+Right`) and next edits,
  plus a Chat view over ACP with GitHub Copilot, Claude Code, and Google Antigravity CLI.
* **Connections and remote hosts:** guided **Add a connection** wizard with QR code and clipboard pairing, automatic
  failover across multiple routes (Wi-Fi, Tailscale, Cloudflare Tunnel with optional Cloudflare Access service tokens),
  and route-aware troubleshooting.
* **Offline and device files:** open device folders directly without a guest, keep guest folders available offline with
  conflict-checked sync, and share, import, or download files and folders through Android's share sheet and file picker.
* **Material You and accessibility:** dynamic colour, light and dark themes, a pure black option, subtle optional
  transitions, and full TalkBack labels across the workbench.

## Known limits

* Android may stop the guest when the tablet is low on memory, or when apps start many background processes; the app
  says so and how to start it again.

To report a problem, use **Settings > About > Copy diagnostics** and paste the report into an issue. Nookra IDE has no
telemetry.
